# Verdant Prelude artwork

Original SVG illustrations created for OCLR S2 (#416): mint washes, paper grain, two swallows with layered flight feathers and forked tails, and three asymmetric leaf shapes with curved veins and translucent colour. Light and dark files use independent palettes. No embedded script, font, external image or network dependency. Original historical key visual remains unchanged at `/archive/s2/key-visual.avif`.

Authoritative assets for the registered theme; the similarly named files under `docs/design/season-themes/s2/` are retained candidate-stage references.
